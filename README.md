# Commerce Engine

Commerce Engine is an AI-powered multi-vendor e-commerce platform designed to support the complete shopping journey from product discovery to checkout, orders, returns, and refunds.

## Features

* Multi-vendor marketplace
* Product & variant management
* Customer, Seller & Admin roles
* Cart & Wishlist
* Checkout & Orders
* Coupons, Tax & Shipping
* Returns & Refunds
* Reviews & Ratings
* AI Shopping Assistant
* Multi-currency support

## Tech Stack

* React + TypeScript
* Node.js + Express
* PostgreSQL / SQLite
* Tailwind CSS
* Google Gemini API

## Setup

```bash
npm install
npm run dev
```

Create a `.env` file and configure the required environment variables.

## Purpose

Built to demonstrate full-stack e-commerce development with AI-assisted product discovery while keeping core transactions, inventory, pricing, and order processing server-controlled.
